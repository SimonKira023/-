# 分享与部署（给别人打开）

## 先说结论

现在浏览器里的 `http://127.0.0.1:8787` **只在你自己的电脑上**，别人打不开。

要让别人打开，有三种方式：

| 方式 | 适合场景 | 需要什么 | 大模型讲解 |
|---|---|---|---|
| A. 发完整版 zip | 同学/评委本地运行 | 对方有 Python + Chrome | 需对方自己配 Key（可选） |
| B. 静态版 + 公网托管 | **提交"体验链接"最推荐** | 免费静态托管账号（Vercel/Cloudflare Pages/GitHub Pages） | 不可用（走本地知识库） |
| C. 同一 Wi-Fi 局域网 | 教室、宿舍现场演示 | 同一网络 | 可用（用你电脑上的 Key） |
| D. 后端容器 + 公网 | 想公网保留大模型 | 云服务器/容器 + Key + 限流 | 可用（Key 在服务端） |

## A. 发完整版 zip 给别人

对方解压后：

1. 双击 `start.bat`（Windows，需要安装 Python 3.10+）
2. 或命令行 `python server/serve.py --port 8787`
3. 打开 `http://127.0.0.1:8787`

> 完整版 zip 已排除 `.env`，**不含你的 Key**；对方想用大模型需要自己填 `.env`。

## B. 静态版 + 公网托管（推荐做体验链接）

`数码考古馆_静态版.zip`（3.2MB）是纯前端版本：

- 不需要服务器、不需要 Key，双击解压后所有交互都能用；
- AI 讲解员自动走**本地知识库**（其余功能与大模型版一致）；
- 已实测：无 `/api` 后端时页面状态显示「在线 · 本地知识库」，带路、摄像机、使用模拟全部正常。

### 部署步骤（Vercel，约 2 分钟）

1. 解压 `数码考古馆_静态版.zip`
2. 打开 https://vercel.com → 登录 → **Add New → Project**
3. 选择 **Deploy without Git** / 直接拖入解压后的文件夹
4. Deploy → 得到 `https://xxxx.vercel.app` 链接，发给任何人都能打开

### 其他托管

- **Cloudflare Pages**：Create project → Direct Upload → 上传文件夹
- **GitHub Pages**：推到仓库 → Settings → Pages → 选分支根目录
- **国内**：阿里云 OSS / 腾讯云 COS 静态网站 + CDN（正式域名需备案）
- **学校服务器**：把文件夹放进任意 Web 目录即可

> 必须通过 HTTP(S) 访问，不能双击 `index.html`（file:// 会拦截 fetch）。
> 本地预览：`python -m http.server 8899`，打开 http://127.0.0.1:8899

## C. 同一 Wi-Fi 局域网演示

```bat
python server\serve.py --host 0.0.0.0 --port 8787
ipconfig    :: 记下 IPv4 地址，例如 192.168.1.23
```

别人在同一 Wi-Fi 下访问 `http://192.168.1.23:8787`。首次可能需要在 Windows 防火墙放行 Python。
注意：这会把你的电脑和大模型 Key 临时暴露给同网络的人，演示完关闭服务。

## D. 公网保留大模型（进阶）

静态托管不能放 API Key（会泄露），需要：

1. 把 `server/serve.py` 部署到有 Python 的容器：Render / Fly.io / Railway / 自己的云服务器；
2. 在容器里配置环境变量 `DEEPSEEK_API_KEY`（或 `ARK_*`）；
3. 让静态页面的 `/api/chat` 反向代理到该服务；
4. **必须加限流/鉴权**，否则链接一旦传播，Key 可能被刷爆。

比赛演示建议：视频里展示大模型模式；体验链接用静态版即可（或部署带限流的后端）。

## 公网分享前检查清单

- [ ] 游客未登录能打开（换浏览器无痕模式测试）
- [ ] 手机 4G 能打开
- [ ] 三个展厅、Agent 带路、摄像机、使用模拟都正常
- [ ] 页面没有 404（尤其 `/api/chat`、`assets/pano/*`）
- [ ] 打开速度可接受（首屏全景图 ~0.5–1.6MB）
- [ ] 公开包里不含 `.env` / 密钥 / 第三方付费素材
- [ ] 素材许可确认（校园比赛一般无碍，商业发布需逐项核对）
